# Contributing

Small learner-sized improvements are welcome: clarify a label or unit, add a provenance note or citation, strengthen a limitation, improve a glossary explanation, or add a test for an existing transformation. Pair authors and reviewers so the group can explain what changed and why.

Do not add OST-controlled data, sensitive locations, community knowledge, tenure information, new management thresholds, or external-facing conclusions through an ordinary contribution. Pause and follow the locally approved governance process described in `documents/data_sovereignty.md`.

Before proposing a change, run `python -m pytest`. Notebook changes should be committed without saved outputs. Deliberate release artifacts require provenance and explicit review status.
