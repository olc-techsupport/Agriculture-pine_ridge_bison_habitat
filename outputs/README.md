# Generated outputs

Outputs are reproducible local products and are ignored by Git by default. They are not approved OLC or OST findings. Precise candidate-patch locations must not be distributed externally before the review and authorization described in `documents/data_sovereignty.md`.

`artifact_manifest.csv` inventories expected products, their generating notebook, source class, sensitivity, and release status. Runtime `bhsi_provenance.json` records input hashes, grid settings, weights, parameters, spatial-variation diagnostics, and governance status.
